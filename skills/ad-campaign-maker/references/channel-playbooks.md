# Channel playbooks

Use this when adapting an ad to a channel or platform.

## Universal rules

- Match platform behavior: feed ads need fast hooks; search ads need intent matching; retargeting can assume the user knows more.
- Keep one main promise per asset.
- Adjust CTA by stage: awareness = follow/watch/learn; consideration = compare/get guide/book demo; conversion = buy/claim/start.
- Create variants by changing angle or audience situation, not only adjectives.

## Short video platforms

Useful for TikTok, Douyin, Reels, Shorts, Kuaishou, and Video Channels.

- Start with a visible 1-3 second hook.
- Hook types: surprising result, myth-busting, before/after, POV, testimonial, demo-first, challenge.
- Keep scenes short and readable without sound.
- Include captions/on-screen text.
- End with one simple CTA.

## Xiaohongshu / lifestyle social

- Use native formats: experience share, checklist, comparison, diary, avoidance guide, before/after routine.
- Avoid hard-sell language unless the user asks for strong promotion.
- Include title options, cover text, body copy, and comment-pinned CTA when relevant.

## Ecommerce product ad

- Lead with problem, desired outcome, or offer.
- Show usage mechanism and scenario.
- Address likely barriers such as price, quality, shipping, fit, trust, and after-sales.
- Make variants for different audiences or use cases.

## B2B lead-generation ad

- Target by role, cost of inaction, and measurable business outcome.
- Offer a low-effort next step: report, demo, consultation, calculator, checklist.
- Use proof placeholders if case data is missing.
- Prioritize specificity and credibility.

## Search ads

- Mirror the keyword intent in headlines.
- Use offer/proof/CTA in descriptions.
- Keep each asset modular.
- Ask for character limits only if the platform or locale requires strict compliance.

## Outdoor / print / display banner

- One message only.
- Large readable headline.
- Short CTA or URL/QR cue.
- Visual hierarchy: product/benefit first, proof second, CTA third.
